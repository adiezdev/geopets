# Geopets Astro + i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn `geopets/index.html` into a static Astro site with English at `/` and Spanish at `/es/`, full SEO, and 145 static SVGs under `/pets/`, keeping every current feature.

**Architecture:** A DOM-free generator module (`src/lib/geopets.js`) shared by the build (static SVG endpoint) and the browser. One Astro page component renders both locales from JSON dictionaries; one vanilla client module (`src/scripts/app.js`) ports the current gallery/creator/download code and reads its strings from an inlined JSON dictionary.

**Tech Stack:** Astro, current stable (static output, built-in i18n), @astrojs/sitemap, jszip, gifenc, vitest.

**Spec:** `docs/superpowers/specs/2026-11-17-astro-i18n-design.md`

## Global Constraints

- Locales: `defaultLocale: "en"`, `locales: ["en","es"]`, `prefixDefaultLocale: false` → `/` and `/es/`.
- `site: "https://geopets.example.com"` in `astro.config.mjs`; every absolute URL derives from `Astro.site`. No `base`.
- `output: "static"`. No runtime CDN: jszip and gifenc imported from npm.
- File names English in both locales: `geopet-{shape}-{state}.{svg|gif}`, HTTP `geopet-{shape}-{code}.{ext}`, packs `geopets-pack.zip`, `geopets-{shape}.zip`, `{slug}-pack.zip`, zip folders `geopets/{shape}/`.
- Shape keys → character names: cube→Cubo, triangle→Tri, circle→Bola, diamond→Rombi, hexagon→Hexa (same names in both locales).
- State keys: `idle happy sad angry love sleeping surprised typing thinking dizzy waving celebrating idea music coffee loading error` + HTTP `200 201 204 301 400 401 403 404 418 429 500 503`.
- License CC BY 4.0; attribution "Geopets by Adiezdev (adiez.dev)"; footer link https://adiez.dev. SVG attribution comment always English.
- Anchors `#gallery`, `#create`, `#license` in both locales.
- Pixel output must be byte-identical in body geometry to the current `index.html` generator (only keys/names change).
- No git repo exists; do not `git init` or commit unless the user asks. Replace "Commit" steps with "Checkpoint: tests green".

## Review Focus

1. Creator with an empty or 1-pixel mask → download/pack buttons show the localized "paint at least one pixel" toast, no crash. (Task 4 test on `layout`; manual check in Task 4.)
2. Pet name with accents/spaces/emoji ("Mi Pétit 🐱") → slug is ASCII `mi-petit`, never empty (falls back to `geopet`). (Task 1 test `slugify`.)
3. Spanish page: every dynamic string (pack button with filter, GIF progress, toasts, LICENSE.txt) is Spanish. (Task 2 key-parity test + Task 4 manual check.)
4. GIF export when the OS has reduced motion on → still produces a 1-frame GIF, no hang. (Task 4: `frameCount([])` returns 1.)
5. Gallery filter "Cube" + pack → `geopets-cube.zip` containing only `geopets/cube/` (29 files) + LICENSE.txt. (Task 4 test on `packEntries`.)
